# 속삭임 대숲

안개 낀 3D 대나무숲에서 하고 싶은 말을 적으면 구름이 되어 떠올랐다가 20초 뒤 흩어지는 한 페이지 웹사이트입니다.

- 바닥을 누르면 그쪽으로 걸어가고, 화면을 좌우로 끌면 둘러볼 수 있어요.
- 아래 입력창에 말을 적고 **띄우기**를 누르면 이름 없이 구름으로 떠올라요 (최대 60자).
- 다른 사람의 구름은 지금은 예시로 떠오르는 문장이에요. 실시간 공유는 아직 없습니다.
- 바람 소리 듣기 버튼으로 숲 소리를 켜고 끌 수 있어요.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열거나 GitHub Pages로 배포하면 됩니다.
3D 그래픽은 three.js r128을 cdnjs에서 불러옵니다.
